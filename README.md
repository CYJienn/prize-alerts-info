# University Prize Alerts

University Prize Alerts is a personal automation for its owner's university mailbox. It reads individual Gmail messages with Gmail read-only permission, finds whole words win, prize or prizes, and sends original relevant excerpts and participation links to the owner's configured private Telegram chat. It does not send or alter Gmail messages. No public sign-up or access to other people's mailboxes is offered.

It runs on a private GitHub Actions repository. Daily scan windows end at 08:00 Asia/Kuala_Lumpur; GitHub execution may be delayed. No AI model is used. Email attachments and image OCR are not processed.
